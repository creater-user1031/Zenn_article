## はじめに

今回は、おみくじアプリで「ランダムに運勢を表示する仕組み」を実装しました。

これまでは入力チェックまでしか実装していませんでしたが、今回はデータファイルからランダムに結果を取得し、HTMLへ表示する流れを学びました。

---

## ランダムな運勢を選択する

今回は、運勢をランダムに取得できるように、`Math.random()` と `Math.floor()` を利用しています。

`Math.random()` は **0以上1未満のランダムな小数** を返します。

しかし、そのままでは配列の番号として利用できません。

そこで、配列の要素数（`length`）を掛け合わせ、最後に `Math.floor()` で小数点以下を切り捨てることで、0から配列の最後までの整数を取得しています。
```javascript
const randomFortuneIndex = Math.floor(Math.random() * omikujiData.length);
const selectedFortune = omikujiData[randomFortuneIndex];
```

さらに、選ばれた運勢の中からパターンをランダムに選択します。

```javascript
const randomPatternIndex =
    Math.floor(Math.random() * selectedFortune.patterns.length);

const selectedPattern =
    selectedFortune.patterns[randomPatternIndex];
```

今回は、以下の運勢だけではなく、同じ運勢の中にも複数の結果を用意しています。

- 大吉
- 吉
- 中吉
- 小吉
- 末吉
- 凶

そのため、運勢が決まったあと、さらにその運勢の中から1つのパターンをランダムで選択しています。

## HTMLへ表示する仕組み

JavaScriptからHTMLを書き換えるために、各要素の取得を行っています。

```javascript
const wishElement = document.getElementById("wish");
```

ここで最初は、

「`wish` と `wishElement` は何が違うのか？」

という疑問がありました。

整理すると、

- `wish` …… データ（オブジェクトのプロパティ）
- `wishElement` …… HTML要素を操作するための変数

という違いがあることを理解できました。

そして、

```javascript
wishElement.textContent = selectedPattern.wish;
```

というコードは、

「ランダムに選ばれたデータの `wish` をHTMLへ表示する」

という意味になります。

## 学んだこと

今回一番理解が深まったのは、

- HTMLは表示する場所
- omikujiData.jsはデータを管理する場所
- script.jsはデータを取得してHTMLへ表示する役割

という3つの役割の違いでした。

また、HTML要素を取得する変数には

```javascript
wishElement
```

のように `Element` を付けることで、自分でも役割が分かりやすくなると感じました。
